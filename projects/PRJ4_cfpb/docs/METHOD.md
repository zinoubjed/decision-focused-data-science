# Privacy, taxonomy, temporal evaluation and abstention

**Source and target.** Official historical narratives exports, all 21 scanned. Product is a consumer-selected label, not a verified intake routing destination. No institution's triage policy is inferred. Public availability is not a guarantee that every narrative is safe to republish.

**Sampling and taxonomy.** Keep IDs whose first eight SHA-256 hex digits modulo 100 are <3. The resulting 115,731-narrative sample is deterministic and bounded. Restrict modeling to 2018-05-01 through 2023-07-31, avoiding the pre-2017 and post-August-2023 taxonomy mixture. Labels are retained as published; classes need >=100 training cases. Counts of excluded classes are explicit (zero in this run), not silently merged.

**Text controls.** Sort by date and ID, remove exact normalized-text repeats before splitting, then regex-scrub email-like strings, phone-like patterns and long numeric tokens. These rules do not detect all names, addresses or identifiers; texts, fitted vocabulary and model bundles stay in ignored local data/processed. Public reports contain class labels and aggregates only. No remote model API is used.

**Temporal/template contract.** Train before 2022; validate in 2022; test from 2023 to July. A character 3–5-gram hashing cosine threshold >=.90 screens validation/test near training and test near retained validation. This is an intentionally conservative diagnostic cohort, not a semantic duplicate guarantee. The filtered result is not a performance estimate for all complaints, especially templated ones. Removed records would still need human review.

**Baseline and selection.** Fit TF-IDF unigrams/bigrams on training only, min_df=3 and max_features=30,000. Compare multinomial NB and logistic regression, selecting on validation macro-F1. Report majority-class accuracy, per-class precision/recall/F1, confusion matrix and rare-class errors. Payday-loan recall is particularly weak in this run, despite strong overall accuracy.

**Abstention.** Select the widest validation coverage among fixed confidence thresholds that accept >=100 cases and have a Wilson lower accuracy bound >=90%. Confidence is not calibrated probability. Threshold .6 yields 3,171 accepted test suggestions, 273 wrong accepted suggestions and 1,506 mandatory reviews on the 4,677 retained test cases. A hypothetical wrong-suggestion cost of 25 units reverses the apparent advantage versus unit-cost review of every record: costs are unknown, so automatic routing is unjustified.

**Local LLM diagnostic.** `cfpb_local_llm.py` uses the same pinned local FLAN-T5-small checkpoint on six retained test cases per class (54 total), with a fixed numbered-label prompt, 1,200-character text limit and 512 input tokens. Only aggregate outcomes are exported. This balanced, small zero-shot diagnostic is not comparable to the full imbalanced temporal test and does not select the production model. See local_llm_diagnostic.json for actual results and latency. No generated complaint excerpts are published.

**Recommendation.** Assisted suggestions only, class-specific quality monitoring, human override and rejection of uncertain/unsupported cases. No legal conclusion about complaints, no causal company ranking, no claim of institutional deployment or measured review productivity.

**Critical-review extension.** See DECISION_NOTE.md and decision_population.json. The original 1,506 mandatory reviews describe only novel retained cases. Including 1,022 exact and 2,519 near repeats produces 5,047 reviews among 8,218 sampled test complaints and 38.59% accepted suggestions. Subgroup accuracy among accepted cases is inadequate for several actual classes; no automatic routing is recommended. All current suggestions should be human-verified. Threshold-search Wilson bounds are descriptive, not post-selection or per-class guarantees. The fresh source-derived sample was verified identical to the original fitted-data sample, and its private cache now checks raw-file and cache SHA-256 provenance.
